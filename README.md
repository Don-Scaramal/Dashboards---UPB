# Dashboards - UPB

Este repositório destina-se ao alojamento, demonstração e partilha de dashboards interativos, ferramentas de visualização de dados e aplicações web desenvolvidas no âmbito dos projetos académicos do Universidade Politécnica de Bragança (UPB).

## 🚀 Objetivo
Servir como montra técnica (portefólio) para simulações interativas, interfaces de controlo e visualizações aplicadas a sistemas de energia, eletrónica de potência e automação.
